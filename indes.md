# Fisherman's Guide

## Site Purpose

Fisherman's Guide is a mobile-friendly website designed to provide basic fishing information in one easy-to-navigate location. The site includes information about fishing conditions, basic fishing gear, helpful fishing tips, and a form that allows users to plan a fishing trip. The application was developed using HTML and jQuery Mobile and was expanded throughout the course as new features were introduced.

## Website Structure

The Fisherman's Guide is organized around a main Home page that provides access to the different sections of the application.

**Site Map**

- Home
  - Fishing Forecast
  - Fishing Gear
  - Fishing Tips
  - Plan a Fishing Trip

The Home page also includes a navigation panel that provides another way to access each section of the application.

## Home Page

The Home page serves as the main navigation area for the application.

- **Fishing Forecast:** Opens the Fishing Forecast page where the user can view and filter fishing conditions.
- **Fishing Gear:** Opens the Fishing Gear page containing a list of basic equipment for a fishing trip.
- **Fishing Tips:** Opens the Fishing Tips page containing helpful fishing information and an ordered list of steps.
- **Plan a Fishing Trip:** Opens a form where the user can enter information about a planned fishing trip.
- **Menu:** Opens the navigation panel containing links to the main sections of the site.

## Fishing Forecast Page

The Fishing Forecast page provides information that can help a user prepare for a fishing trip. A filterable list allows the user to enter text and narrow the displayed fishing conditions.

- **Filter/Search:** Filters the list based on what the user enters.
- **Back:** Returns the user to the previous page.

## Fishing Gear Page

The Fishing Gear page provides basic information about equipment a fisherman may need. An unordered list is used to organize the different pieces of fishing equipment.

- **Back:** Returns the user to the previous page.

## Fishing Tips Page

The Fishing Tips page provides basic advice for preparing for and completing a fishing trip. An ordered list presents the information in an easy-to-follow sequence.

- **Back:** Returns the user to the previous page.

## Plan a Fishing Trip Page

The Plan a Fishing Trip page contains a form that collects information about the user's planned fishing trip. The form includes multiple fields where the user can enter trip information.

- **Form Fields:** Allow the user to enter information about the planned fishing trip.
- **Submit:** Submits the information entered into the form.
- **Back:** Returns the user to the previous page.

## Navigation Panel

The navigation panel provides quick access to the main sections of Fisherman's Guide without requiring the user to return to the Home page first.

- **Fishing Forecast:** Opens the Fishing Forecast page.
- **Fishing Gear:** Opens the Fishing Gear page.
- **Fishing Tips:** Opens the Fishing Tips page.
- **Plan a Fishing Trip:** Opens the fishing trip form.
- **Close Menu:** Closes the navigation panel.
